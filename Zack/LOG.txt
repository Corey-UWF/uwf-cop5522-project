2026-11-22 - Adaptive equal-row MPI implementation
------------------------------------------------------------
AI-assisted development:
Verified Rolando's project1_fileio_blas_adaptive_v21.c and adapted its
128-column blocked sparse kernel and OpenBLAS SGEMM computation into
mpi_adaptive.c. Kept mpi_baseline.c unchanged. Retained equal-row CSR
distribution, dense broadcasts, and output gathering.

Algorithm:
H <= F selects A(XW): rank 0 computes XW and broadcasts the intermediate.
H > F selects (AX)W: replicate X and W and compute both local stages.
Single-precision storage and arithmetic; one OpenBLAS thread per rank.
Root-only XW is a potential serial bottleneck, not a proven speedup.

Timing:
MPI_Wtime phase measurements report maximum rank times for CSR
distribution, root XW, dense broadcast, local kernels, and gathering.
Total includes allocation and instrumentation barriers but excludes
file I/O, initial metadata exchange, partition setup, and reductions.
Phase maxima should not be added to infer total runtime.

Validation:
Built the new MPI source with GCC -O3 -std=c11 -Wall -Wextra -pedantic
-Werror using isolated MPICH 4.0 and OpenBLAS 0.3.20 packages under WSL.
No system packages were installed.
Compared outputs against sequential v21 and an independent calculation
with the criterion abs(actual-reference) <= 1e-4 + 1e-4*abs(reference).
Five cases tested at 1, 2, and 8 ranks:
- F=7, H=3: A(XW)
- F=3, H=7: (AX)W
- F=4, H=4: equal-dimension tie selects A(XW)
- F=131, H=130: sparse block tail after column 128
- F=3, H=7 with no nonzeros: zero output
All cases passed; each used five rows, including empty rows and more
ranks than rows at eight ranks. Verified all six timing fields were
finite/nonnegative and OpenBLAS reported one thread even when the
environment requested four. Invalid CSR pointers terminated the
two-rank test with an explicit error.

Limits:

**2026-11-22 - Nonzero-balanced MPI implementation and local validation**
------------------------------------------------------------

Created mpi_balanced.c from the current mpi_adaptive.c without modifying
mpi_adaptive.c or mpi_baseline.c. The repository adaptive source still
includes cblas.h; the balanced source uses explicit LP64 CBLAS/OpenBLAS
declarations to support the stated cs-ssh header limitation.

Rank 0 selects complete contiguous row boundaries nearest cumulative
p*nnz/P targets. Scaled int64_t comparisons retain fractional targets and
avoid count-product overflow. Ties select the preceding boundary; repeated
boundaries and duplicate row pointers are valid. Zero-nonzero matrices use
equal-row partitions. All six partition metadata arrays are broadcast
before distribution. Local CSR pointers are checked against local nnz.

Preserved both evaluation orders, blocked sparse kernel, SGEMM, single
BLAS thread, dense broadcasts, gathering, output format, and phase timers.
Added assigned-row/nonzero summaries, nonzero imbalance ratio, and reduced
minimum/maximum/mean local kernel times. Zero-nonzero imbalance is N/A.
Setup/metadata and extra diagnostic reductions remain outside total timing.

Validation environment:
Local WSL, MPICH 4.0, OpenBLAS 0.3.20, GCC -O3 -std=c11
-Wall -Wextra -Werror -pedantic. Dependencies were extracted into isolated
session storage, not installed system-wide.

test_balanced_partition.c passed eight focused cases, including near-INT_MAX
targets, duplicate pointers, dominant rows, zero nonzeros, excess ranks,
and exact count/displacement coverage.

test_balanced_mpi.py passed 27 configurations against both equal-row
adaptive MPI and sequential v21, at absolute/relative tolerance 1e-4:
- N=4000, F=128, H=64, nnz=64000
- N=4000, F=64, H=128, nnz=64000
- Empty rows
- Dominant high-degree row
- More ranks than rows
- Zero nonzeros
- Sparse feature-block tail
- Power-law-style irregular rows, both evaluation orders
Each input ran at 1, 2, and 4 ranks. Primary outputs matched v21 exactly.
Reverse comparisons had maximum absolute errors of 0, 6.1e-05, and 4.6e-05
at 1, 2, and 4 ranks respectively, all within tolerance. These deterministic
test inputs are not claimed to reproduce Rolando's frozen benchmark files.
Partition diagnostics and six finite/nonnegative phase/total timings were
also verified. The initial excess-rank unit-test expectation was corrected
to select the earlier boundary for an exact midpoint tie.

No performance improvement or ACCESS/multi-node validation is claimed.
Whole-row nonzero balancing cannot divide a single dominant row, and it
does not balance row-dependent dense work in (AX)W. Root-only XW, dense
replication, communication, and synchronization remain potential limits.
